The idea is to keep track of characters' frequency, for that purpose we use hash map. Also we need to check if the window is valid and includes replacing the characters. To learn that we can calculate `window_length - max_count <= k`. In this condition we have a valid longest repeating character replacement in a window, the moment this condition becomes false we shift our left window until it is met again. We store the best values and update if found a better one and return it
